MCP quickstart

# 1. Get token from extension sidepanel
export BV_TOKEN=your-token
# 2. Search bookmarks via API (MCP server wraps the same endpoints)
curl -H "Authorization: Bearer $BV_TOKEN" "$API_BASE/v1/bookmarks?q=agent"
# 3. MCP config (Claude Desktop / agents)
{
  "mcpServers": {
    "bookmarkvault": { "command": "npx", "args": ["bookmarkvault-mcp"],
      "env": { "BV_TOKEN": "your-token", "API_BASE": "https://api.example.com" } }
  }
}

Tools exposed: search_bookmarks, list_labels, recent_digests.
