## The one decision that changes the pitch

`python3 roi.py --sweep`. At cheap-model prices the audit does **not** pay for itself on
tokens (10 loops x 100 turns on DeepSeek-class: $1.4k/year → 769 working days). It pays
on:

- **expensive models**: 10 loops on Opus-class → 18 working days;
- **volume**: 100 loops x 200 turns on cheap models → 38 working days;
- **operator time**: `--hourly 50` on the same cheap fleet → 98 working days, because the
  wall tax survives cheap tokens (312 wall-hours/year, of which 65 h is boot).

If a prospect is none of those, say no. `objections.md` opens with exactly this.

## What was retracted tonight (do not sell these)

| claim | status |
|---|---|
| cache state predicts wall / "miss rate 5 in 10" | did not reproduce — paper §6 |
| "startup scans ~200 MB of sessions" → startup-scan fix | startup does not scale with the session store — paper §7 |
| size coefficient "1 s + 0.5 ms/KB" | 10x off its own table, and the ladder would not rebuild — paper §8 |
| "the LLM is free / unaccounted is harness overhead" | partly a clock artifact; the provider window is 1.2-1.6 s before the harness's own start event — paper §5, §5.4 |

What replaced them: **boot (372 ms warm / 940 ms cold, removable) + pre-response (1.45 s, a bound we can
measure and cannot split) + stream (2 ms)**, and the live-fleet numbers (500 real turns:
8.7 s/turn, 34% model / 29% tools / 37% unaccounted — that last 37% is the *pre-v23* reading:
with `preResponseMs` measured it is the provider round-trip, and what is left unattributed is
p50 4 ms, paper §9 — plus 4.4% wasted turns).

## Standing rule for this pack

A number goes in the copy only if a script in this pack recomputes it (`roi.py`,
`analyze.py`) or the sentence labels it PRIOR / ASSUMPTION. When a claim is retracted,
fix every file that carries it in the same pass — grep the phrase, not the file.
