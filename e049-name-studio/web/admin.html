Esta sección es solo para el admin. Inicia sesión una vez y quedas autenticado 24h (token en tu navegador). Otras personas pueden usar la app sin ser admin — su configuración queda local.

IA global

Si dejas API Key = ${OPENCODE_GO_API_KEY} y Base URL = ${OPENCODE_GO_BASE_URL}, el servidor usará las env vars del sistema. El Modelo ya está por defecto en muse-spark-1.2-contributor (el de esta sesión). Cámbialo solo si quieres otro.

Diseño de autenticación — cómo pensarlo

Dos niveles:
1) Global (admin / servidor): lo que guardas aquí afecta a todos. Solo tú con password/token puedes cambiarlo. Usa env vars para no exponer keys en disco.
2) Local (visitante / navegador): cada persona que abre name.studio puede poner su propia IA en el panel izquierdo (“¿Tu propia IA?”) — eso se guarda solo en localStorage de su navegador y se envía como header x-user-ai-key por request. No toca el servidor ni molesta a otros. Ideal si alguien quiere usar su key sin ser admin.

Flujo auth: Login → token 24h en localStorage → todas las llamadas admin usan x-admin-token sin pedir password cada vez. Si alguien no es admin, ve la app normal pero /admin le pide login. Las preferencias personales nunca requieren login.
Recomendación: deja la API key global como ${OPENCODE_GO_API_KEY} y modelo en muse-spark-1.2-contributor — así hereda lo que ya usamos aquí y no duplicas secretos.
