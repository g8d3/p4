¿Cómo se calcula pronunciable / memorable?

Son heurísticas locales, no IA — rápidas y explicables:

  • 🗣️ pronunciable (0-100): + penaliza clusters de 4+ consonantes (vxzt), + premia proporción vocales 35-55% (luma ideal). 90-100 = suena natural, 50 = con trabas.
  • 🧠 memorable (0-100): promedio de corto (4-7 letras = 90) + pronunciable. Corto + fácil de decir = se recuerda. No es magia, es longitud + fonética.

Idea que dejaste registrada: en el futuro estos scores podrían ser una página donde pegas una lista y se ordena por cualquier columna — por ahora ya puedes ordenar la tabla arriba por Pron / Mem / Letras / A-Z y filtrar con “Solo disponibles / ≤6”.
