## Facts
- Bitquery: real-time GraphQL API + WebSocket streaming + Snowflake/BigQuery warehouse; Personal $49 / Pro $99 / Scale $299; 7-day trial no CC. Chains include Solana, Ethereum, Tron, Base, Arbitrum, Optimism, BSC, Polygon (full count — verify).
- Dune: SQL queries + community dashboards + API; credit-based; Free $0 (2,500 query credits/mo per Sept-2026 third-party check; dashboard viewing free); 14-day trial of paid features. Warehouse latency (batch, minutes-scale — widely known, verify current freshness SLA).
- Flipside: SQL + curated datasets + AI agents; 30+ chains; tiered seat-based plans (Analyst ~$75/mo, Plus ~$399/mo per third party — verify); free tier historically offered — verify.
- Decentralization: all three hosted platforms.
- Self-host: no for all three.
