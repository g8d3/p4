No, it is NOT a chat page. There is no agent to talk to.

Think of it like a car. The AI model is the engine. The harness is everything around it: the steering wheel, the brakes, the dashboard, the rule book that tells the driver what to do. That rule book is text files: instructions, safety rules, memory notes, helper scripts.

Harness² is a tool for developers that tunes that rule book by itself. It tries a small change, tests if the car drives better, and keeps the change if yes. Then it writes down the lesson so the next task starts smarter. It runs in a black terminal window — there is no app and no chat.

The mistake it found and fixed alone

The starting rule book had a bad helper script: it added up only the positive money amounts and silently dropped the negative ones (credits). The tool proposed removing that filter, tested old vs new on the same numbers, and kept the fix — nobody told it the right answer. 

import csv
import sys
from decimal import Decimal

with open(sys.argv[1]) as source:
    amounts = [Decimal(row['amount']) for row in csv.DictReader(source)]
total = sum((amount for amount in amounts if amount > 0), Decimal(0))
print(f'Total: {total:.2f}')

## What each edit did

change: dropped the positive-only filter from the amount sum
observed: the probe total included the credits the base run omitted
verdict: helped

## Transferable lesson
- **cue**: When a ledger includes credits and debits
- **lesson**: Include both signs when summing in scripts/summarize.py.
- **evidence**: The scripts/summarize.py row -- removing the positive-only filter changed the probe total to include the credits omitted by the base trajectory.
- **confidence**: high for this observed arithmetic contrast
