e077 — Live Reload Loader

What: install-once loader (extension .zip or userscript .user.js) that hot-injects live.js + card.html from your PC. Edit on PC, phone updates in ~1s. No reinstall loop.

Status

checking dev server…

Run

  1. Set SERVER to http://<PC-LAN-IP>:8080 in ext/content.js and live-reload.user.js
  2. node server/server.js 8080
  3. Install once, straight from this server on your phone: extension .zip or userscript .user.js (open in Queta)
  4. Edit server/public/live.js, save, watch the phone
